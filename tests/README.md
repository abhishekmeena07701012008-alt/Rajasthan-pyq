3. टेस्ट का उद्देश्य

इन टेस्ट से जाँच होगी:

- PYQ Import Preview सही रिपोर्ट बनाता है या नहीं।
- डुप्लिकेट प्रश्न पहचाने जाते हैं या नहीं।
- Hindi और English प्रश्न उपलब्ध हैं या नहीं।
- प्रश्नों के आधिकारिक स्रोत की जानकारी मौजूद है या नहीं।
- Answer Key का स्रोत दिया गया है या नहीं।
- Import Workflow सही रिपोर्ट तैयार करता है या नहीं।

4. महत्वपूर्ण सुरक्षा नियम

- टेस्ट पास होने का अर्थ यह नहीं है कि प्रश्न असली PYQ है।
- वास्तविक PYQ की पुष्टि मूल प्रश्नपत्र से करनी होगी।
- सही उत्तर की पुष्टि आधिकारिक Answer Key से करनी होगी।
- Admin की समीक्षा के बिना कोई प्रश्न Verified घोषित नहीं होगा।
- ये टेस्ट प्रश्नों को Firebase में अपलोड नहीं करते।

5. अंतिम जाँच

सभी मॉड्यूल पूरे होने के बाद पूरे प्रोजेक्ट की जाँच की जाएगी। इसमें imports, dependencies, Firebase Functions, database rules और Android build शामिल होंगे।
